A toggle chip for stackable wallpaper layers and for single-choice sets such as aspect ratio and shadow style. Pressed state is `accent` fill with `accent-ink` text, set through `aria-pressed`; unpressed is `field` with a `line` border. Text is `chip` (mono 12px). Chips wrap, 6px apart. Layers are multi-select; ratio and shadow style are single-select. The consumer provides the label and keeps the selected set. A layer that needs extra input (Fibonacci side, the vertical label text) shows that control under the chip row, only while the layer is on. A hint line in `hint` explains the last toggled layer.
